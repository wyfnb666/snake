# 贪吃蛇 · Snake

一个零依赖的网页版贪吃蛇，支持**单人**与**双人同屏对战**。纯 HTML + Canvas + 原生 JS，双击 `index.html` 即可游玩，不需要构建、不需要安装任何东西。

## 玩法

### 单人
- 方向键或 WASD 转向，空格暂停，R 重开
- 吃果实 +10 分，每吃 4 个加速一点（有上限）
- 三档速度各自记录最高分（存在 localStorage）

### 双人同屏
- **P1 用 WASD**，**P2 用方向键**
- 开局中间有一道围墙，把场地平分左右；两人各自半场、各自有等量果实
- **撞到围墙立刻判负**；围墙时长可在右侧选择（10 秒 / 20 秒 / 30 秒 / 无）
- 围墙消失后，果实回到单人规则（全场 1 个），两人抢同一个
- 撞到自己或对方的身体同样判负；先出局的一方输，同时出局算平局
- 是否允许穿墙在开局前选择；围墙期内只在自己半场环绕，不能借环绕穿墙

### 视觉区分
- P1 墨黑，P2 朱红，且 P2 头部多一圈白描边，黑白打印或色弱也能分辨
- 果实为橄榄绿，不与任一玩家撞色

## 本地运行

直接双击 `index.html`。想用本地服务器也可以：

```bash
npx serve .
# 或 python -m http.server 8080
```

## 测试

```bash
node game.test.js
```

56 项纯逻辑测试，覆盖：移动、吃食、180° 掉头限制、尾巴格判定、撞墙/撞自己/撞对方、双人围墙规则、围墙时长自定义、胜负与平局判定。

## 结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面与样式（纸张 / 印刷风格） |
| `game.js` | 纯逻辑：移动、碰撞、食物生成、围墙与胜负判定（不碰 DOM，可在 Node 下测试） |
| `app.js` | 渲染（Canvas）、输入（键盘 + 触屏方向键）、主循环 |
| `game.test.js` | 逻辑测试 |

逻辑与渲染分离，所以规则可以在无浏览器环境下验证。
